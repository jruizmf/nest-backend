A production-grade RESTful API built with the [NestJS framework](https://github.com/nestjs/nest), featuring authentication, database integration, and continuous integration.

## 🚀 Features

* **Authentication & Authorization**: Pre-configured JWT token validation and role-based access control (RBAC).
* **Database Management**: Database ORM implementation using Prisma/TypeORM with strict migration tracking.
* **Input Validation**: Request payload sanitization and strict type validation using `class-validator`.
* **API Documentation**: Automated OpenAPI specification interactive UI using Swagger.
* **Docker Support**: Containerized local environment and multi-stage production builds.

## 📋 Prerequisites

Ensure you have the following tools installed locally:

* [Node.js](https://nodejs.org) (v20.x or higher)
* Package Manager (NPM, Yarn, or PNPM)
* Docker & Docker Compose (for running localized database containers)
